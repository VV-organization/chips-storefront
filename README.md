# Chips
Тёмный магазин скинов CS2, пополнений Steam и карт Apple. Курс: **1 ₽ = 1,7 Chips**.

## Запуск
Node.js 24. `npm ci`, затем `npm run dev`. Локально: http://127.0.0.1:5301.

`npm test` — денежная модель, фильтры, бюджетный подбор, storage, валидация, интеграционные границы.
`npm run typecheck`, `npm run lint`, `npm run build` — Next.js приложение.
`npm run build:pages` — статический export в `out-pages` с basePath `/chips-storefront`.
GitHub Actions публикует ветку `codex/chips-storefront`.

## Возможности
68 товаров со снимка; каталог, поиск, фильтры, сортировка, избранное; быстрый просмотр и страницы товаров; корзина с сохранением; локальные настройки кабинета; Спектр и конструктор с закреплением; формы Steam, Chips, Apple и двусторонний конвертер. Все поверхности тёмные, предусмотрен reduced-motion. Сравнение использует подвижную границу A/B; списки заменены тёмными панелями выбора с поиском, превью и клавиатурным управлением.

## Границы
Каталог — датированный снимок с исходными source-полями, не текущие остатки. Сохраняются рублёвые цены, отображаемые исходным Gems: они пересчитаны в Chips отношением 17/10. Повторный расчёт из raw provenance намеренно не применяется, чтобы не менять старую рублёвую цену.

Steam OpenID, платежи, реальная выдача и поставщик Apple не подключены. Все финансовые операции отвечают unavailable; клиент не создаёт баланс, заказы или коды. Локальный кабинет не является авторизацией Steam. Для коммерческого запуска нужны серверные контракты, ledger, провайдеры и юридические сведения.
