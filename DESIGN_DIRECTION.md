# Chips — graphite / coral
Пространственная графитовая сцена, настоящие изображения скинов, крупный строгий гротеск, фрагменты и тонкая сетка из референсов. Контент/маршруты из исходного ТЗ. Весь интерфейс тёмный. Акцент не занимает целые секции.

| Token | HEX | Использование |
|---|---|---|
| background | #0C0D10 | Страница |
| surface | #14161B | Карточки/формы |
| surface-raised | #1C1F25 | Диалоги и активные поверхности |
| surface-hover | #252930 | Hover нейтральных элементов |
| text | #F4F5F7 | Основной текст |
| text-secondary | #ADB2BD | Подписи |
| text-muted | #8B929F | Метаданные |
| border | #30353F | Декоративные разделители |
| border-control | #707987 | Границы интерактивных полей |
| accent | #FF5949 | Основные действия |
| accent-hover | #FF7668 | Hover |
| accent-active | #E84B3D | Pressed |
| on-accent | #0C0D10 | Текст на коралле |
| focus | #FFA298 | 2px outline с offset 3px |
| error | #FF8992 | Ошибки с текстом и aria |
| error-surface | #32191F | Фон ошибки |

На коралловых кнопках тёмный текст; белый мелкий текст на #FF5949 не используется. Декоративный border не заменяет контрастную границу поля. Ошибки отличаются от брендового акцента розовым оттенком и подписью. Результаты численной проверки — reference-evidence/contrast.json.
