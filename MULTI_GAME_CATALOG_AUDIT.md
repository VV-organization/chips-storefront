# Мультигровой каталог Chips

Источник по запросу пользователя: https://shop-skin.com/catalog. Дата: 12 октября 2026. Все изменения локальные; commit, push и deploy не выполнялись.

## Реализация

- Три игры: CS2, Rust, Team Fortress 2. Категории и полный ассортимент импортируются из публичного каталога. `public/catalog-data/<game>.json` — отдельный компактный индекс игры; описания разбиты на небольшие файлы по префиксу ID.
- Скрипты `scripts/import-reference-catalog.py`, `scripts/import-cs2-categories.py` и `scripts/prepare-reference-catalog.py` сохраняют источник, дату, категории, исходные цены, оригинальные названия и изображения. Импорт читает только открытый каталог; не использует вход, корзину или платёжные методы референса.
- Выбор игры — три явные кнопки в стиле Chips. Для длинных категорий — существующая тёмная панель с поиском и управлением с клавиатуры. Поиск, категории, четыре сортировки, избранное, цена и дополнительные CS2-фильтры. Выбор сохраняется в URL. По 24 предмета с кнопкой «Показать ещё».
- Карточка, быстрый просмотр, отдельная статическая страница `/item?game=…&id=…` и корзина показывают правильную игру. Износ CS2 не применяется к Rust, TF2 и аксессуарам без износа. Неизвестный float не придумывается.
- 68 прежних товаров и HD-изображения главной сохранены. Их ранее сохранённое избранное доступно в CS2. Полный новый каталог не загружается на главной странице.
- Новые товары в корзине сохраняют только локальные данные для отображения; эти цены не используются для авторизации платежа. Добавление заменяется ссылкой в корзину, плашка работает внутри диалога, повторы ID исключены.
- Курс референса: 1 Creeps = 1,7 ₽. Исходные сотые Creeps сначала переводятся в копейки, затем в сотые Chips по 1 ₽ = 1,7 Chips. Оба шага — целочисленный half-up. Пример: 5,04 Creeps → 8,57 ₽ → 14,57 Chips.
- Для дорогих коллекционных товаров расширен предел отображения и фильтра цены. Семизначный предел ввода суммы пополнения остался прежним.
- Анимация каталога начинается после гидратации React: атрибуты появления больше не изменяют серверную разметку до подключения каталога.

## Проверено в браузере

- Rust: поиск `hoodie` → 164 результата; сортировка А–Я; «Показать ещё» увеличивает 24 до 48; избранное сохраняется после обновления.
- Rust: Weapon → 1747 предметов. Смена игры сбрасывает категорию.
- TF2: поиск категории `Rocket` с клавиатуры → Rocket Launcher → 17 предметов.
- Rust и TF2: quick view → добавление → плашка → корзина → обновление. Оба предмета сохранены, ссылка вместо повторного добавления. Диалог закрывается при переходе. Тестовые товары удалены.
- Проверены Escape и возврат фокуса на выбор категории; неверный диапазон цены показывает ошибку, сброс восстанавливает результаты.
- Совместная корзина прежнего AK-47 с главной и импортированного Rust-предмета сохраняет обе позиции. После проверки тестовые добавления удалены.
- Самый дорогой Rust-предмет (17 314 604,96 Chips) проверен в быстром просмотре и корзине при 320 px; переполнения нет.
- Desktop: плашка внутри диалога, нижний отступ 21 px. Mobile: длинное имя предмета и плашка полностью помещаются, изображение не пересекает подписи.
- 320, 390, 768 и 1440 px: проверены переключатели, фильтры и карточки; горизонтального переполнения нет на проверенных экранах.

## Ограничения

Это датированный локальный снимок ассортимента, а не подключение коммерческой системы поставщика. Остатки и цены не обновляются в реальном времени; оформление реальной покупки по-прежнему недоступно. Изображения новых предметов загружаются с исходных публичных адресов Steam; при сетевой ошибке показывается явное сообщение. Они не перегенерировались и не подменялись вымышленными предметами.

## Данные и сверка

- В снимке: **28 454 CS2 / 5 019 Rust / 628 TF2 = 34 101 предмет**. Категорий: 18 / 5 / 104.
- CS2 обходился по всем категориям с двух сторон сортировки, с перекрытием страниц. Во время обхода источник менялся: исходный общий счётчик 28 466, сумма счётчиков при повторной сверке 28 592. Снимок не является атомарной копией текущих остатков; его счётчик отражает сохранённые уникальные ID.
- У **922 позиций CS2** источник не предоставил изображение, в том числе у ряда наклеек. Они сохранены в ассортименте; показывается «Изображение недоступно». У Rust и TF2 таких позиций в снимке нет.
- Индексы: CS2 13,2 MiB; Rust 1,44 MiB; TF2 0,16 MiB. Загружается выбранная игра, описания — отдельно по необходимости.
