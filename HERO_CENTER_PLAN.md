# Центральная композиция hero

Запрос: попробовать центральное выравнивание первого экрана.

1. Общая ось для заголовка, описания, CTA, оружия и управления.
2. Сохранить живой фон и движение трёх предметов; выделить безопасную область изображения.
3. Проверить desktop, tablet и mobile: целые изображения, отсутствие наложений, переключение и quick view.
4. Выполнить typecheck, lint и сборку; сохранить скриншоты результата.

Выполнено: композиция по общей центральной оси, адаптивный заголовок, отдельная область для движущегося предмета, центрированные подпись/цена и горизонтальный переключатель.

Проверка: AK-47, Glock-18, M9 Bayonet; viewport 320, 390, 768, 1512 и 1920 px. DOM-геометрия: изображения внутри области, подписи и переключатель внутри hero, горизонтального переполнения нет. Quick view открывается и закрывается Escape, CTA открывает каталог. Typecheck, lint, build:pages (74 страницы), git diff --check пройдены. Скриншоты и замеры: reference-evidence/chips-hero-centered-*.png и hero-centered-checks.json.

## Коррекция: один экран и более крупный предмет
- Высота hero равна доступной высоте viewport за вычетом шапки.
- Сократить вертикальные отступы; на desktop объединить нижнее управление в один ряд.
- Отдать свободную высоту предмету, увеличить масштаб AK с учётом прозрачных полей исходника; проверить все предметы и короткие экраны.

Коррекция выполнена и проверена: hero + шапка = высота viewport на 1512×850, 1512×700, 768×1024, 390×844, 320×568 для всех трёх предметов. Управление остаётся внутри первого экрана, горизонтального переполнения нет. AK на desktop 1512×850 увеличен с 454 до 698 CSS px по ширине изображения. Сохранены анимация и центральная ось. Typecheck, lint и build:pages пройдены.
